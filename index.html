Privacy Policy — NEONLOTUS Pin Manager

Last updated: 27 July 2026

Who we are

NEONLOTUS Pin Manager is a private, personal-use tool built and operated by the owner of the Etsy shop NEONLOTUS (neonlotuscreations.etsy.com), which sells digital spreadsheet and printable templates for small businesses. It is not a public product: it is not distributed, published, sold, or made available to any other person or organisation.

Contact: neonlotus77@gmail.com

What the application does

The application connects to the Pinterest API v5 using the owner's own Pinterest business account, via the standard OAuth 2.0 authorisation flow. It is used to:

  • read the owner's own boards, pins and pin analytics;
  • publish new pins for the owner's own products, including title, description, alt text and a link to the corresponding Etsy listing.

What data we access

Only data belonging to the owner's own Pinterest account:

  • account information (username, account type, follower counts);
  • the owner's own boards and pins;
  • analytics for the owner's own pins (impressions, saves, clicks, outbound clicks).

We do not access, collect, request, or process data belonging to any other Pinterest user. The application has no other users, no sign-up, no user accounts, and no server component.

What data we store, and where

  • OAuth tokens (access token and refresh token) are stored locally, on the owner's own computer only, in a file that is excluded from version control and never shared.
  • Analytics and pin data retrieved from Pinterest are written to local report files on the same computer, for the owner's own marketing analysis.

There is no database, no cloud storage, no hosting, and no transmission of data to any server other than Pinterest's own API endpoints.

What we do not do

  • We do not share, sell, rent, publish, or transfer any data to third parties.
  • We do not use any advertising, analytics, or tracking service.
  • We do not collect personal data from Pinterest users, visitors, or customers.
  • We do not ask for or store Pinterest login credentials. Authorisation is granted only through Pinterest's official OAuth flow.

Data retention and deletion

Local files can be deleted by the owner at any time. Authorisation can be revoked at any moment from Pinterest account settings (Settings → Security and permissions → Apps), which immediately invalidates the tokens held by the application.

Children's privacy

The application is not directed at children and does not knowingly process any data relating to children.

Changes to this policy

Any change to this policy will be published on this page, with an updated date at the top.

Compliance

The application is operated in accordance with the Pinterest Developer Guidelines and, as the owner is based in France, with the GDPR. As no third-party personal data is processed, no data processing register or data protection officer is required.
